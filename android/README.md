# Rootweave Trusted Web Activity

Package: **`com.cortexdevelopments.rootweave`** (Cortex Developments).

Not Manager Schedule Pro. Never use `com.managerschedulebuilder.pro`.

Wraps the live PWA at `https://bryanralston.github.io/rootweave/` with start URL

`https://bryanralston.github.io/rootweave/?store=play`

so the in-app Gumroad coin shop stays hidden. Ordinary mobile browsers (no `store=play`) keep the web shop.

This is a checked-in Gradle TWA (android-browser-helper `LauncherActivity`), same shape as a bubblewrap project. Re-running `bubblewrap init` is optional; `twa-manifest.json` is here if you want that later.

## Assemble on a machine with Android SDK

```bash
# From repo root
export ANDROID_HOME=/path/to/Android/sdk   # or ANDROID_SDK_ROOT
cp android/keystore.properties.example android/keystore.properties
# create an upload keystore, then:
keytool -genkeypair -v -keystore android/upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias rootweave
cd android
./gradlew bundleRelease
# AAB: app/build/outputs/bundle/release/app-release.aab
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

If `keystore.properties` is missing, `bundleRelease` still compiles but the AAB is unsigned. Play Console needs a signed AAB (any upload key you own).

`local.properties` with `sdk.dir=` is generated by Android Studio; do not commit it.

## Digital Asset Links

See `../.well-known/README.md`. Chrome looks up **`https://bryanralston.github.io/.well-known/assetlinks.json`** (host root). Paste the Play **App signing** SHA-256 there after the Play app exists.
